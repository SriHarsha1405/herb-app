# Herbal Ingredient Explorer

A web application that allows users to explore various herbal ingredients, their benefits, and compare them. It offers an interactive experience where users can add ingredients to their wellness stack, compare different ingredients, and track their personal wellness journey.

## Features

- **Ingredient Exploration**: Search and explore various herbal ingredients.
- **Wellness Stack**: Add ingredients to your personalized wellness stack.
- **Ingredient Comparison**: Compare the effects and benefits of selected ingredients.
- **Wellness Challenges**: Take part in wellness challenges to track your progress.
- **User Profiles & Favorites**: Create a profile, save favorite ingredients, and track your wellness journey.

## Technologies Used

- **HTML5**: For structuring the web pages.
- **CSS3**: For styling the pages and components.
- **JavaScript**: For adding interactivity (search, add to stack, comparison).
- **Local Storage**: For saving user data like favorites and wellness stacks.
- **Responsive Design**: Optimized for both mobile and desktop devices.
